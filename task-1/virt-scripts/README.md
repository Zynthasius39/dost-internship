# Scripts for provisioning virtual machines using ```virt-install```

## 1. Install a new SSH key
``` sh
$ ./generate-key.sh
```

## 2.1 Initialise an AlmaLinux 10.1 VM
``` sh
$ ./install-alma.sh
```

## 2.2 Initialise an ArchLinux VM
``` sh
$ ./install-arch.sh
```

## 2.3 Initialise an Debian Trixie VM
``` sh
$ ./install-debian.sh
```
